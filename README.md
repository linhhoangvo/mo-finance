# Mô Finance

A lightweight real-estate finance management app for acquisition, renovation, rental operations, loans and property sales.

## V1

- Dashboard
- Properties
- Transactions
- Loans
- Rentals
- Sales
- Reports
- Add-transaction dialog
- Browser localStorage persistence
- Responsive UI
- No production financial data committed to the repository

## Run locally

Open `index.html` in a browser.

## GitHub Pages

In the repository, go to **Settings → Pages → Build and deployment → Deploy from a branch**, then select:

- Branch: `main`
- Folder: `/ (root)`

The V1 intentionally uses localStorage only. A later version can add authentication and a real database (for example Supabase/Postgres) after the financial model and screens are confirmed.

## Data model direction

- Properties
- Transactions
- Loans
- Rental operations
- Sales
- Capital sources
- Reporting

> Important: keep the repository private before adding real financial, legal or personal data.
